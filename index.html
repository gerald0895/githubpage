IDENTIDAD · ZERO TRUST

Microsoft Entra PIM (Privileged Identity Management)

Implementación de acceso privilegiado bajo demanda (Just-In-Time) para eliminar privilegios permanentes y reducir la superficie de ataque en roles críticos de Azure y Microsoft 365.

  • Activación temporal (JIT) con aprobación obligatoria y justificación de negocio.
  • MFA resistente al phishing para Global Admin, Security Admin e Intune Admin.
  • Revisiones periódicas de acceso (Access Reviews) y alertas de auditoría.
Entra ID PIM RBAC Just-In-Time
IDENTIDAD · ZERO TRUST

Arquitectura Conditional Access & Zero Trust

Diseño y despliegue de motor de políticas adaptativas basadas en identidad, riesgo de sesión y postura del dispositivo para proteger aplicaciones empresariales.

  • Bloqueo de autenticación heredada (Legacy Auth) y geolocalización no autorizada.
  • Acceso condicionado a dispositivos marcados como Compliant en Intune o Hybrid Joined.
  • Remediación automática de riesgo de usuario/sesión vía Entra ID Protection.
Conditional Access Zero Trust MFA
INTUNE & ENDPOINTS

Unión Híbrida (AD → Intune) y Migración de Políticas

Integración de Active Directory On-Premise hacia Microsoft Entra ID e inscripción automática en Intune, modernizando directivas tradicionales (GPO).

  • Microsoft Entra Connect Sync y Hybrid Entra Join sin interrupción operativa.
  • Migración de GPOs críticas a Settings Catalog y Security Baselines de Intune.
  • Hardening de endpoints Windows mediante perfiles de restricción y firewall.
Hybrid Entra Join GPO to MDM Security Baselines
INTUNE & ENDPOINTS

Implementación de Flotas Corporativas con Intune

Gestión centralizada del ciclo de vida de flotas corporativas (Windows, iOS/Android) con aprovisionamiento automatizado y cumplimiento continuo.

  • Despliegue Zero-Touch mediante Windows Autopilot por perfiles departamentales.
  • Cifrado BitLocker con respaldo en Entra ID y rotación automática de claves LAPS.
  • Distribución de apps Win32, Windows Update for Business y borrado remoto.
Microsoft Intune Autopilot BitLocker / LAPS
INFRAESTRUCTURA · REDES

Seguridad Perimetral FortiGate, VPN & Virtual Wire Pair

Fortalecimiento de redes perimetrales y segmentación transparente mediante firewalls FortiGate con inspección profunda UTM y alta disponibilidad.

  • Implementación de Virtual Wire Pair para inspección IPS/UTM inline sin alterar el direccionamiento IP existente.
  • Túneles VPN Site-to-Site IPsec y SSL VPN con doble factor de autenticación (2FA).
  • Control de aplicaciones, Web Filtering, SD-WAN y análisis de tráfico en tiempo real.
FortiGate UTM Virtual Wire Pair IPsec / SSL VPN
INFRAESTRUCTURA · DRP

Veeam Backup, Disaster Recovery & Virtual Labs

Arquitectura de respaldo inmutable (regla 3-2-1-1-0) y continuidad operativa asegurando tiempos RPO/RTO críticos frente a fallos o ransomware.

  • Configuración de Virtual Labs y SureBackup para verificación automática de recuperación y pruebas en entornos aislados.
  • Repositorios inmutables (Hardened Linux Repository) protegidos contra cifrado malicioso.
  • Replicación de máquinas virtuales críticas y recuperación granular de bases de datos.
Veeam B&R Virtual Labs RPO / RTO
INFRAESTRUCTURA · CORE

Active Directory, Windows Server, IIS & PowerShell

Administración, endurecimiento (Hardening) y automatización de servicios de directorio empresarial, servidores web y roles críticos Windows Server.

  • Diseño de jerarquía de OUs, delegaciones administrativas, DNS/DHCP redundantes y GPOs corporativas.
  • Despliegue seguro de aplicaciones web en IIS con certificados TLS 1.3 y cabeceras de seguridad.
  • Scripts en PowerShell para auditoría de cuentas inactivas, aprovisionamiento y reportes.
Active Directory Windows Server / IIS PowerShell
INFRAESTRUCTURA · M365

Exchange Online & Seguridad Perimetral de Correo

Arquitectura de flujo de correo corporativo y protección anti-phishing mediante integración de Exchange Online con Secure Email Gateways.

  • Implementación estricta de registros SPF, DKIM y DMARC (p=reject) para prevenir suplantación de dominio.
  • Conectores seguros entre Microsoft 365 y Perimeter Mail Gateway con reglas de transporte DLP.
  • Políticas Anti-Phishing, Safe Links, Safe Attachments y cuarentena administrada.
Exchange Online SPF/DKIM/DMARC Mail Gateway
INFRAESTRUCTURA · ITSM

ITSM, Inventario de Activos & Azure DevOps

Gobierno de servicios TI, gestión de cambios (CAB) y trazabilidad completa del inventario tecnológico corporativo bajo mejores prácticas ITIL.

  • Implementación de ManageEngine ServiceDesk Plus para incidentes, SLAs, CMDB y ciclo de vida de activos.
  • Planificación ágil de proyectos de infraestructura y control de cambios con Azure DevOps.
  • Planificación de capacidad, auditoría de licenciamiento y cumplimiento operativo.
ServiceDesk Plus Azure DevOps CMDB / ITIL
CIBERSEGURIDAD · SOC

Operaciones SOC/SIEM & Respuesta EDR/XDR

Monitoreo continuo 24/7, correlación de telemetría y contención temprana de amenazas combinando inteligencia SOC con defensa activa en endpoints.

  • Integración de telemetría crítica en Cyrebro (SIEM/SOC) para detección y caza de amenazas.
  • Despliegue y políticas anti-ransomware con Sophos EDR/XDR y Microsoft Defender.
  • Playbooks de Incident Response para aislamiento automático de endpoints comprometidos.
Cyrebro SIEM/SOC Sophos XDR Incident Response
CIBERSEGURIDAD · GRC

Vulnerability Management, NIST & Seguridad Cloud

Programa continuo de remediación automatizada de vulnerabilidades, Security Assessments y madurez de controles bajo el marco NIST CSF.

  • Descubrimiento, priorización basada en riesgo y remediación automatizada con Vicarius.
  • Ejecución de Security Assessments y controles en entornos Microsoft Azure y AWS.
  • Gobierno y cumplimiento sobre las funciones Identify, Protect, Detect, Respond y Recover (NIST).
Vicarius NIST CSF Azure & AWS
